# Daniel Yousef — Creative Workspace

A responsive personal portfolio inspired by the Photoshop workspace.

## Features

- English and Arabic content
- 11 portfolio projects with filters and project details
- Senior Graphic Designer | Team Leader profile
- Original portrait and downloadable CV
- Canvas themes, accent colors, zoom and keyboard navigation

## Run locally

No build or dependencies are required. Serve this folder with any static web server, for example:

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080.

## GitHub Pages

The site files are at the repository root. For a repository eligible for GitHub Pages, choose the `main` branch and `/ (root)` in **Settings → Pages**.

## Structure

- `index.html` — workspace layout
- `style.css` — styles and responsive layouts
- `app.js` — content and interactions
- `assets/` — portfolio images, portrait and original CV
